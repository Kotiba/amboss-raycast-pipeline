## Summary

Cardiac arrhythmias are accelerated, slowed, or irregular <u>heart rates</u> caused by abnormalities in the electrical impulses of the <u>myocardium</u>. <u>Bradyarrhythmias</u> include <u>sinus node dysfunction</u> and <u>atrioventricular block</u>, and are characterized by a <u>resting heart rate</u> < 60/minutes. <u>Tachyarrhythmias</u> (<u>heart rates</u> > 100/minute) are classified as <u>supraventricular arrhythmias</u> or <u>ventricular arrhythmias</u>. <u>Supraventricular arrhythmias</u> originate between the sinus node and the <u>atrioventricular node</u>. <u>Ventricular arrhythmias</u> originate below the <u>atrioventricular node</u>, on the ventricular level. This article provides an overview of cardiac arrhythmias based on the <u>heart rate</u> and site of origin of the arrhythmia. For details of the individual arrhythmias, see the corresponding articles. For the medical treatment of arrhythmias, see the article on <u>antiarrhythmic drugs</u>.

---

## Classification

### <u>Bradyarrhythmias</u>




* Definition: <u>heart rates</u> of < 60/min

* Types: see <u>bradyarrhythmias</u> below





### <u>Tachyarrhythmias</u>



* Definition: <u>heart rate</u> of > 100/min




#### <u>Supraventricular arrhythmias</u>




* Definition: arrhythmias that originate in the <u>sinoatrial node</u>, atrial <u>myocardium</u>, or <u>atrioventricular node</u> (regular <u>QRS complex</u>)

* Types: see <u>supraventricular tachyarrhythmias</u> below





#### <u>Ventricular arrhythmias</u>




* Definition: arrhythmias that originate below the <u>atrioventricular node</u> (wide <u>QRS complex</u>)

* Types: see <u>ventricular tachyarrhythmias</u> below

| <br>Second-degree block <br> | <br><br>* Drugs: <u>digoxin</u>, <u>beta blocker</u>, <u>calcium channel blocker</u><br><br>* Increased <u>vagal</u> tone<br><br>* Sinoatrial conduction disease<br><br>* Right coronary <u>infarction</u><br><br><br> | <br><br>* <u>Mobitz type I</u>/Wenckebach: progressive lengthening of the <u>PR interval</u> until a beat is dropped<br><br>* <u>Mobitz type II</u>: irregular dropped beats<br><br><br> |  |
| <br>Third-degree block <br> | <br>* Complete block: no communication between the <u>atria</u> and ventricles<br><br> | <br>* <u>AV dissociation</u>: no relationship between <u>P waves</u> and <u>QRS complexes</u><br><br> |  |

## Tachyarrhythmias

### <u>Supraventricular arrhythmias</u>




| Type of <u>tachyarrhythmia</u> |  |  | Causes and mechanisms | Main <u>ECG</u> findings |  |  |
| --- | --- | --- | --- | --- | --- | --- |
| Atrial origin |  |  |  |  |  |  |
| <br><u>Supraventricular premature beats</u> <br> |  |  | <br><br>* Physiological response in healthy individuals<br><br>* <u>Electrolyte</u> imbalances<br><br>* Underlying cardiovascular disease<br><br><br> | <br>* <u>P wave</u> abnormalities or absent <u>P waves</u><br><br> |  |  |
| <br><u>Sinus tachycardia</u> |  |  | <br>* <u>Sympathetic</u> activation or <u>vagal</u> withdrawal on the <u>SA node</u><br><br> | <br><br>* Gradual onset<br><br>* Regular rhythm<br><br>* Rate: max. rate usually 180 bpm<br><br>* <u>P wave</u>: normal morphology<br><br>* Narrow <u>QRS complex</u><br><br><br> |  |  |
| <u>Atrial flutter</u> |  |  | <br>* Macroreentrant rhythms within the <u>atria</u><br><br> | <br><br>* Regular rhythm<br><br>* Rate: atrial 250–350; ventricular < 200<br><br>* <u>P waves</u><br><br>* Occur before every <u>QRS complex</u><br><br>* Sawtooth appearance of regular <u>P waves</u> (<u>flutter waves</u>) especially in leads II, III, and <u>aVF</u><br><br>* Narrow <u>QRS complex</u><br><br><br> |  |  |
| <br><u>Atrial fibrillation</u> <br> |  |  | <br>* Multiple mechanisms which are not completely understood<br><br> | <br><br>* Rhythm: irregularly irregular<br><br>* Rate: 350–450 bpm; < 200<br><br>* <u>P-waves</u> are indiscernible<br><br>* Narrow <u>QRS complex</u><br><br><br> |  |  |
| <br><u>Atrial tachycardia</u> (∼ 5%) |  | <u>Focal atrial tachycardia</u> | <br>* Discharge from a single ectopic focus in the <u>atrium</u><br><br> | <br><br>* Very abrupt onset<br><br>* Regular rhythm<br><br>* Rate:  150–250<br><br>* <u>P wave</u>: morphology varies depending on the site of the <u>ectopic focus</u><br>* Occurs before the <u>QRS complex</u><br><br>* Narrow <u>QRS complex</u><br><br><br> |  |  |
| <br><u>Multifocal atrial tachycardia</u> (<u>MAT</u>)  <br> | <br><br>* Discharge from multiple <u>ectopic foci</u> in the <u>atrium</u><br><br>* Associated with pulmonary disorders (e.g., <u>COPD exacerbation</u>, <u>pulmonary embolism</u>), cardiac conditions (<u>CHF exacerbation</u>), and treatment with <u>theophylline</u><br><br><br> | <br><br>* Very abrupt onset with rate variation<br><br>* Rhythm: irregularly irregular<br><br>* Rate: 150–250<br><br>* Discernible <u>P waves</u> with ≥ 3 different <u>P wave</u> morphologies; no single morphology is predominant<br><br>* Narrow <u>QRS complex</u><br><br><br> |  |  |  |  |
| <u>AV node</u> origin |  |  |  |  |  |  |
| <u>Atrioventricular reentry tachycardia</u> (<u>AVRT</u>) |  |  | <br><br>* A form of <u>paroxysmal supraventricular tachycardia</u><br><br>* <u>Tachycardia</u> caused by an <u>accessory pathway</u> between the <u>atria</u> and ventricles<br><br><br> | <br><br>* Very abrupt onset<br><br>* Regular rhythm<br><br>* Rate: 150–250<br><br>* <u>P wave</u><br><br>* Inverted (downgoing in II, III and <u>aVF</u> and/or upright in aVR)<br><br>* Occur after the <u>QRS complex</u><br><br>* <u>RP interval</u> is shorter than <u>PR interval</u><br><br>* <u>QRS complex</u><br><br>* <u>Orthodromic AVRT</u>: narrow <u>QRS complex</u><br><br>* <u>Antidromic AVRT</u>: wide <u>QRS complex</u> with delta waves<br><br><br> |  |  |
| <br><u>AV nodal reentry tachycardia</u> (<u>AVNRT</u>) <br> |  |  | <br><br>* A form of <u>paroxysmal supraventricular tachycardia</u><br><br>* A dysfunctional <u>AV node</u> that contains two electrical pathways<br><br><br> | <br><br>* Regular rhythm<br><br>* Rate: 150–250<br><br>* <u>P waves</u> occur during (i.e. are not visible) or after the <u>QRS complex</u><br><br>* <u>RP interval</u> is shorter than <u>PR interval</u><br><br>* Narrow <u>QRS complex</u><br><br><br> |  |  |
| <br><u>Junctional tachycardia</u> <br> |  |  | <br><br>* The <u>AV node</u> takes over the pacemaker function<br><br>* <u>Digitalis toxicity</u><br><br>* <u>Myocarditis</u><br><br>* <u>Myocardial infarction</u><br><br><br> | <br><br>* Regular rhythm<br><br>* Rate: 100–130<br><br>* <u>P waves</u> occur before, during, or after the <u>QRS complex</u><br><br>* <u>P waves</u> are inverted<br><br>* <u>AV dissociation</u> may occur<br><br>* <u>Narrow QRS complex</u><br><br><br> |  |  |





### Ventricular arrhythmias




| Type of arrhythmia | Causes and mechanisms | <u>ECG</u> findings |
| --- | --- | --- |
| <br><u>Premature ventricular beats</u> <br> | <br><br>* <u>Ectopic</u> beat that originates from a ventricular focus<br><br>* Due to <u>hypoxia</u>, <u>hyperthyroidism</u>, <u>electrolyte</u> abnormalities<br><br><br> | <br><br>* Premature, wide <u>QRS complex</u>  that is not preceded by a <u>P wave</u><br><br>* <u>Compensatory pause</u> after the premature beat<br><br><br> |
| <br><u>Ventricular tachycardia</u> <br> | <br><br>* <u>Coronary artery disease</u><br><br>* <u>Myocardial infarction</u><br><br>* <u>Structural heart diseases</u><br><br><br> | <br><br>* Regular, rapid rhythm<br><br>* Wide <u>QRS complexes</u> (≥ 3 consecutive <u>premature ventricular beats</u>)<br><br>* <u>Monomorphic VT</u> (most common): single QRS morphology<br><br>* <u>Polymorphic VT</u>: multiple QRS morphologies<br><br>* <u>AV dissociation</u> (<u>P waves</u> may or may not be discernible)<br><br><br> |
| <br><u>Torsade de pointes</u> <u>tachycardia</u> <br> | <br><br>* Associated with <u>Long QT syndrome</u><br><br>* Proarrhythmic drugs<br><br>* <u>Electrolyte</u> abnormalities (<u>hypokalemia</u>)<br><br><br> | <br>* Polymorphic <u>ventricular tachycardia</u> with <u>QRS complexes</u> that appear to twist around the isoelectric line<br><br> |
| <br><u>Ventricular fibrillation</u> <br> | <br><br>* <u>Myocardial infarction</u><br><br>* <u>Structural heart diseases</u><br><br><br> | <br><br>* Arrhythmic, fibrillatory baseline, usually > 300 bpm<br><br>* Erratic undulations with indiscernible <u>QRS complexes</u><br><br><br> |
